# Adda Wali Embroidery Design ✨

About adda wali embroidery design - Traditional Punjabi handwork meets modern style.

### 🌸 What is Adda Work?
Adda work is a traditional embroidery style where fabric is stretched on a wooden frame (Adda) and heavy embroidery is done with zari, beads, and threads. Famous in Ludhiana / Punjab for bridal suits.
